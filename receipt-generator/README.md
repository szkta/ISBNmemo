# 領収書自動発行ツール

Excel に宛名・金額・但し書きなどを入力しておくと、1 行ごとに領収書 PDF を自動で発行するツールです。

## 特長

- **Excel で管理**: 1 行 = 1 枚。宛名・敬称・金額・但し書き・税率・支払方法・備考を入力
- **控え付き**: A4 の上半分が領収書、下半分が控え (`--no-copy` で領収書のみ)
- **インボイス対応**: 登録番号、税率ごとの税抜金額・消費税額 (8% 軽減税率にも対応) を記載
- **収入印紙欄**: 金額が 5 万円以上の場合は自動で貼付欄を表示
- **自動採番**: 領収書番号が空欄なら `R-YYYYMMDD-001` 形式で採番し、Excel に書き戻し
- **二重発行防止**: 発行した行には「発行済」日時を記入し、次回以降はスキップ
- **印影**: 印影画像 (PNG) を指定すると押印した状態で出力
- **一括 PDF**: 個別 PDF に加え、全件をまとめた印刷用 PDF も出力

## セットアップ

Python 3.10 以上が必要です。

```bash
cd receipt-generator
pip install -r requirements.txt
```

## 使い方

### 1. Excel テンプレートを用意

同梱の `receipts_template.xlsx` をコピーして使うか、次のコマンドで新規作成します。

```bash
python receipt_generator.py init receipts.xlsx
```

### 2. Excel に入力

**「発行者情報」シート** に、自社の情報を入力します。

| 項目 | 例 |
|---|---|
| 発行者名 | 株式会社サンプル商事 |
| 郵便番号 / 住所 / 電話番号 | 〒100-0001 / 東京都千代田区… / TEL 03-… |
| 登録番号 | T1234567890123 (インボイス登録番号。不要なら空欄) |
| 担当者 | 任意 |
| 印影画像 | `seal.png` (Excel ファイルからの相対パス可。不要なら空欄) |

**「領収書データ」シート** に、1 行 1 枚で入力します (サンプル行は削除してください)。

| 列 | 必須 | 説明 |
|---|---|---|
| 発行日 | | 空欄なら発行した日 |
| 領収書番号 | | 空欄なら自動採番 |
| 宛名 | ✔ | 例: 株式会社テスト |
| 敬称 | | 様 / 御中 / 殿 (空欄なら「様」) |
| 金額(税込) | ✔ | 税込の金額 (`12,000` や `１２，０００円` も可) |
| 但し書き | | 空欄なら「お品代として」 |
| 税率(%) | | 10 / 8 / 0 (空欄なら 10) |
| 支払方法 | | 現金・銀行振込など |
| 備考 | | 任意 |
| 発行済 | | ツールが自動で記入。空欄に戻すと再発行対象になる |

列の順番は自由です (見出しの名前で判別します)。

### 3. 発行

Excel を保存して **閉じてから** 実行します。

```bash
python receipt_generator.py issue receipts.xlsx -o output
```

`output/` に `R-20261006-001_山田_太郎.pdf` のような個別 PDF と、全件をまとめた `領収書_一括_*.pdf` が作成されます。

### オプション

| オプション | 説明 |
|---|---|
| `-o, --out DIR` | 出力先フォルダ (既定: `./output`) |
| `--all` | 発行済の行も含めてすべて再発行 |
| `--no-copy` | 控えを付けず、領収書のみ出力 |
| `--no-combined` | まとめ PDF を作らない |
| `--no-mark` | Excel に領収書番号・発行済を書き戻さない |
| `--font PATH` | PDF に埋め込む日本語フォント (.ttf / .ttc) を指定 |

## フォントについて

文字化けを防ぐため、PC にある日本語 TrueType フォントを自動で探して PDF に埋め込みます
(Windows: MS ゴシック / メイリオ、Linux: IPA フォントなど)。

macOS 標準のヒラギノは埋め込みに対応していないため、Mac では
[IPAex フォント](https://moji.or.jp/ipafont/) の `ipaexg.ttf` を `receipt-generator/fonts/` に置くか、
`--font` で .ttf を指定してください。

## 計算ルール

- 消費税額 = 税込金額 × 税率 ÷ (100 + 税率) (1 円未満切り捨て)
- 税抜金額 = 税込金額 − 消費税額
- 金額 5 万円以上で収入印紙貼付欄を表示 (控えには表示しません)
